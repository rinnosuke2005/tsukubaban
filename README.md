## エレベーターピッチ

統計が足りず卒論・研究で悩んでいる学生向けの、アンケート募集サイト「つくばばん」。
手軽にたくさんのサンプルを入手でき、LINEやInstagramとは違って知り合いに頼らないため、サンプルの偏りを減らすことができる。
